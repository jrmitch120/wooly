Mastodon, from your terminal

Read, post and script Mastodon without leaving the shell.

Wooly is a cross-platform terminal client for Mastodon, written in .NET. It comes as two programs that share one API, sign-in and config layer, so you sign in once and both act as the same profile.

Download the latest release View on GitHub

Single self-contained executables for Linux, macOS and Windows. No .NET install needed.

wooly-tui

An interactive, keyboard-driven shell for reading and posting. A rail of destinations sits beside a content panel, and esc walks you back out the way you came.

$ wooly-tui

wooly-cli

A scriptable command line with --json output, errors on stderr and documented exit codes that scripts can branch on.

$ wooly-cli timeline home --limit 40 --json

What it does

Both front ends

  • Home, local, federated and hashtag timelines, plus any account's posts, replies and pinned posts
  • Write, reply to, edit and delete posts, with content warnings, attachments and alt text, polls, visibility and language
  • Boost, favorite, pin, and vote in polls
  • Notifications, direct messages, and follow requests for a locked account
  • Follow, mute and block accounts, and edit your own public profile
  • One search across accounts, hashtags and posts
  • Several profiles, across one instance or many
  • Sign-in through your browser (OAuth). Wooly never asks for your password.

The TUI

  • A rail of destinations (Timelines, Hashtags, Explore, Inbox, You) with a breadcrumb you walk back out of
  • Tag sets: a few hashtags, followed on the rail as one timeline
  • Pictures drawn inline on terminals that speak sixel or the Kitty graphics protocol, and linked with their alt text everywhere else
  • Live unread counts on the Inbox from the instance's streaming API, with an optional bell
  • Compose on its own screen, with mention and language pickers, a file browser, and pasting from the clipboard
  • Mouse support, an adjustable shell width, a hideable rail, and themes you write yourself
  • Respects NO_COLOR and TERM=dumb

The CLI

  • --json on lists, searches, shown posts and accounts, and what you publish
  • A list comes as an envelope that says whether the fetch was complete
  • Results on stdout, errors on stderr
  • Exit codes that keep their meaning: 0 success, 1 general, 2 usage, 3 auth, 4 network, 5 rate limited

Install

Download the executable for your platform from the latest release. Each one is a single self-contained file.

PlatformTUICLI
Linux x64wooly-tui-linux-x64.tar.gzwooly-cli-linux-x64.tar.gz
macOS Apple siliconwooly-tui-macos-arm64.tar.gzwooly-cli-macos-arm64.tar.gz
macOS Intelwooly-tui-macos-x64.tar.gzwooly-cli-macos-x64.tar.gz
Windows x64wooly-tui-windows-x64.exewooly-cli-windows-x64.exe

On Linux and macOS, unpack the tarball and run what's inside:

tar -xzf wooly-tui-macos-arm64.tar.gz
./wooly-tui

Linux needs the ICU libraries (libicu). Desktop and server distributions usually have them; minimal container images usually don't.

macOS builds aren't signed or notarized. Extracting with tar on the command line is usually enough to get past Gatekeeper. If macOS still refuses, clear the quarantine flag with xattr -d com.apple.quarantine ./wooly-tui.

Get started

In the TUI

Run wooly-tui. With no profile set up yet, it opens on Add a profile: type your instance (for example mastodon.social), sign in through the browser it opens, and give the profile a name. You land on your home timeline.

Press ? on any screen to see its keys, and ctrl-p for profiles.

tab shift-tabMove along the rail
j kNext / previous post
⏎Open the post
c rCompose / reply
b fBoost / favorite
/Search
escBack one level (never quits)
ctrl-qQuit

From the CLI

wooly-cli profile add work --instance mastodon.social

This opens your browser to authorize Wooly, then checks the token before saving the profile. With no browser, the address is printed so you can finish signing in somewhere else.

The first profile you add becomes the default; --profile <NAME> picks another for one run.

# A post with a content warning and a described picture
wooly-cli post create "Look who turned up" --cw "cat pics" \
  --media "cat.png:a ginger cat asleep on a keyboard"

# A poll that stays open for two days
wooly-cli post create "Tabs or spaces?" --poll tabs --poll spaces --poll-open 2d

# Search for a hashtag
wooly-cli search "#dotnet"
